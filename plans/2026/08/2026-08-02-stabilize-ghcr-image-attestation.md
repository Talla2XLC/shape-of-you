# Стабилизация публикации attestations в GHCR

## Цель

Устранить гонку между публикацией OCI-образа и загрузкой provenance attestation в GHCR, не ослабляя обязательные проверки поставки.

## Область работ

- обновить GitHub attestation action до актуального контракта;
- добавить требуемое разрешение для artifact metadata;
- перед attestation ограниченно ожидать доступность опубликованного manifest по digest;
- применить одинаковое поведение к API и edge образам;
- проверить синтаксис workflow и каноническую документацию.

## Критерии готовности

- attestation запускается только после того, как GHCR возвращает manifest по digest;
- временная недоступность GHCR обрабатывается ограниченными повторами;
- постоянная ошибка остаётся блокирующей и не скрывается через `continue-on-error`;
- локальные проверки проходят.

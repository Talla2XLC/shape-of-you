## Выполнение

1. Дождаться успешного staging deployment commit `94afe51`.
2. Получить отдельное подтверждение staging writes для четырёх перечисленных id.
3. Для каждого id вызвать append-only `correct_meal`, сохранив исходные
   `occurredAt`, `timezone`, `kind` и описание.
4. Выполнить `list_meals(localDate)` для обеих дат.
5. Проверить новые current records, `supersedesId`, числовые totals и отсутствие
   неполных manual Meal за эти даты.

- Исходные фото проверены read-only и оценки уточнены.

# Проверка идей из Fitness Tracker

Статус: завершено 2026-09-29; `EPIC-0001` закрыт.

## Цель

Сохранить полезные незакрытые идеи из [листа Ideas](https://docs.google.com/spreadsheets/d/1yUPcU-2RGIOPyfz8HzR6NSHuztwps81PHbzlGzcK2Ik/edit#gid=310000002) после переноса источника данных в Shape of You. Статусы `Accepted` и `Done` в старой таблице не считаются доказательством готовности текущего API. Текущий источник истины о поведении — каноническая Wiki, ADR, задачи и проверенный код.

## Не создавать повторно

- `IDEA-001`: обязательное закрытие дня заменено capture-first Coach; возвращать его без нового продуктового решения не нужно.
- `IDEA-007`: многодневный риск нагрузки уже реализован.
- `IDEA-008`: импорт доступных Garmin-данных работает через Intervals.icu; ограничения покрытия метрик остаются явными.
- `IDEA-009`: базовый веб-интерфейс уже реализован в `DEV-025`; более широкие сценарии требуют отдельного продуктового решения. Telegram-бот — альтернатива, не дополнительное обязательство.
- `IDEA-010`–`012`: канонические Markdown Wiki/ADR уже ведутся в репозитории; не создавать второй управляемый источник документации.

## Границы этого плана

План фиксировал продуктовый отбор, не разрешая изменение приложения, схемы БД,
миграций, инфраструктуры или старой таблицы. Дальнейшие задачи выбираются по
конкретному пользовательскому трению, а не автоматически из старого листа.

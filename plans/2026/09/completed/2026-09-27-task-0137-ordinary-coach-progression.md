# TASK-0137 — прогрессия в обычном разговоре о следующей силовой тренировке

## Цель

Дать Coach повод самостоятельно прочитать готовое безопасное решение о весе и
повторениях, когда пользователь обсуждает выполнение следующей силовой
тренировки, без лишних вызовов в других разговорах.

## Утверждённое решение

- [ADR](../../../../docs/adr/20260927-invoke-progression-in-ordinary-next-strength-coaching.md):
  изменить только MCP-инструкцию вызова существующего инструмента.
- `Daily Assessment` разрешает или ограничивает сегодняшнюю тренировку;
  прогрессия поясняет параметры только разрешённого точного силового шага.
- Совет не создаёт подходы из Garmin, не обещает будущую готовность и не
  изменяет активную программу.

## Шаги

1. Зафиксировать scope и план в TASK-0137 через `4dt-board`.
2. Уточнить операционную инструкцию Coach и описание read-only инструмента.
3. Добавить положительные и отрицательные MCP contract tests; проверить
   существующий server-side Recovery gate.
4. Выполнить локальные проверки, независимый Quality Review и Architecture
   Review; после принятия обновить только затронутую current-state Wiki.

## Критерии приёмки

- Обычный разговор о параметрах следующего точного силового шага при
  `ready` и `follow_active_program` вызывает прогрессию после оценки и
  контекста; прямой вопрос остаётся поддержан.
- Разговор без разрешённого точного шага и посторонние темы не вызывают
  ненужную прогрессию; ограничение восстановления не обходится.
- Coach объясняет только typed результат: оставить вес, добавить повторения,
  осторожно повысить вес либо недостаточность evidence.
- Нет Garmin set inference, обещания будущей готовности или автоматического
  изменения active program.
- Тесты, docs validation, независимая проверка качества и Architecture Review
  пройдены. Коммит, push и deploy вне scope.

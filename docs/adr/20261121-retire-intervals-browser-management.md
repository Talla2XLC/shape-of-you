# Оставить на сайте только прямое подключение Garmin

## Context

Intervals использовал только оператор, который уже переведён на прямой Garmin.
Оператор прямо потребовал удалить с сайта всё, связанное с Intervals: новым
пользователям этот способ подключения и механизм перехода не нужны.
Это явное согласование изменения пользовательского сценария от 2026-11-21.

## Decision

На `/connections` оставить только Garmin Personal API. Удалить браузерные
компоненты, запросы управления Intervals и переходом, связанные сообщения и
устаревшие UI tests. Сохранить ввод ключа, статус синхронизации, замену ключа,
отключение, запрос истории и удаление Garmin-данных с существующим подтверждением.
Исправить компоновку страницы отдельными стилями без изменения остальных экранов.

Сохранённая история, provenance, серверные API, границы перехода и операционные
механизмы не меняются. Это решение отменяет браузерный сценарий управления
переходом из TASK-0181, но не его правила владения данными и восстановления.

## Considered alternatives

- Скрыть старые карточки условием: оставляет ненужный браузерный код и риск
  повторного появления сценария; не соответствует требованию удалить его с сайта.
- Удалить также серверный адаптер и исторические данные: выходит за пределы
  запроса и затрагивает сохранённую историю и восстановление; отклонено.
- Удалить только старый UI и browser adapters: выбранный минимальный вариант.

## Consequences

Новый пользователь видит единственный путь подключения. Legacy maintenance
остаётся операционной задачей; сайт не предлагает создавать Intervals connection
или управлять переходом. Публичные серверные схемы и миграции не меняются.

## Verification

Browser tests проверяют единственный Garmin flow, отсутствие legacy-текста и
запросов, работающие действия и безопасные ошибки. Desktop/mobile screenshots
проверяют верхний отступ, читаемость и расстояния. Независимые Quality и
Architecture Review обязательны перед завершением.
